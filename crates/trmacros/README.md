# trmacros

Procedural macros for Terrarium. No features are enabled by default.

- `scene`: `instance!` and its expansion helper, re-exported by `trscene`.
- `devtools`: the `Inspect` derive, re-exported by `trrendert::devtools` and `trdevtools`.
- `engine`: `#[with_workspace]`, re-exported by `trengine`.
